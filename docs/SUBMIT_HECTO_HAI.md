## 프로젝트명
HUNT Purse — 공모전 상금·참가비를 다루는 AI 월렛 코파일럿

## 한 줄
Octet API + 오하이월렛으로 **상금 입금·팀 정산·다음 응모 예산**을 자동 추천하는 월렛 기반 AI 웹서비스.

## 문제
공모전 사냥꾼은 상금이 여러 계좌/팀원으로 흩어지고, 다음 응모 참가비·도구비를 감으로 쓴다.

## 솔루션
1. HUNT가 추천한 타깃의 예상 상금·참가비를 월렛 예산으로 연결
2. 오하이월렛으로 상금 수령 / 팀 지분 정산
3. Octet API로 결제·이체 흐름을 웹서비스에 붙임
4. AI가 “이번 상금의 얼마를 다음 Nebius/해커톤 크레딧에 넣을지” 근거와 함께 제안

## 데모 범위 (1차)
- `/wallet` 상금 장부 UI (실현 수익 ↔ 목표 1억)
- 타깃별 예산 배분 추천 API
- Octet/오하이 연동 스텁 → 키 발급 후 실결제

## 비즈니스 모델
프리미엄 사냥꾼 구독 + 팀 정산 수수료(소액) + B2B(캠퍼스타운 운영 월렛)

## 다음 사용자 액션
1. DAKER 해커톤 페이지에서 HAI 챌린지 **참가/팀 생성**
2. Octet / 오하이월렛 개발자 키 발급 (계정 연동)
