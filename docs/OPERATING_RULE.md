# 운영 규칙 (사용자 vs 에이전트)

## 사용자에게만 요청하는 것
- 회원가입 / 계정 생성
- 로그인·OTP·소셜 로그인 (이 실행 환경 브라우저·MCP에 세션이 없을 때)
- API 키·결제수단·본인인증 등 비밀·계정 발급

## 에이전트가 직접 하는 것
- 이미 가입된 플랫폼에서의 폼 작성, 클릭, 제출, 팀 참가, 파일 업로드 준비
- 이메일 접수 공모전 발송 (Gmail 등 연결된 경우)
- 데모·문서·코드·영상 준비

로그인 벽이 나오면 “이 환경에서 해당 서비스 로그인”만 요청하고, 제출 클릭은 다시 에이전트가 수행한다.
