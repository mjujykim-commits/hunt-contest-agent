## 해결하는 문제 (포항/글로벌)
지역 창업팀·글로벌 빌더가 공고를 찾는 데 시간을 쓰고, 상금만 큰 대회에 몰려 승률이 떨어진다. 포항 글로컬 창업 생태계에서도 ‘어떤 대외활동·지원에 쏠지’ 결정 비용이 크다.

## 솔루션
- 다출처 공고 통합 (국내+글로벌)
- EV(상금×추정승률) / 적합도 / 마감 긴급도 / 투입일수 랭킹
- Why + 소스 인용형 추천
- 응모 큐·매출 장부와 연결되는 운영 OS
